# Security policy

Flowmo is private during the current beta. Report a potential vulnerability to
Fran Carrara through the private project channel. Do not include sensitive data
in a public issue.

Please include the affected revision, reproduction steps, impact, and any safe
mitigation you found. Attach a redacted diagnostic report when it is relevant;
never attach a full data export unless the owner explicitly requests it through
a private channel.

There is no published security-reporting address yet. A confidential channel
accessible to every tester is a release blocker before external beta access.
