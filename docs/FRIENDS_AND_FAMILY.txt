FLOWMO — FRIENDS & FAMILY MAC PREVIEW

Version 1.0 (build 8)
Requires macOS 14 Sonoma or newer. Works on Apple silicon and Intel Macs.

BEFORE YOU OPEN IT

This is a Mac release candidate. It is not signed with
an Apple Developer ID and has not been notarized by Apple, so macOS cannot
verify it and will show a warning. This ZIP contains only the Mac app. The
separate iPhone app can be built from source with Xcode; it is not included here.

Only continue if you received the ZIP directly from Fran or obtained it from
the project’s official GitHub Releases page, and its SHA-256 value matches the
provided checksum. For a private preview, compare the checksum sent separately.
The official project release page is:
https://github.com/francarraras/flowmo-dev/releases

If macOS says the app "will
damage your computer" or that the app is damaged, stop and contact Fran. Do not
override that warning.

INSTALL

1. Double-click the Flowmo ZIP to unzip it.
2. Open the unzipped folder.
3. Drag Flowmo.app into your Applications folder.
4. Open Flowmo from Applications.

FIRST OPENING

The first opening will probably be blocked because this preview is not
notarized. After you have tried to open Flowmo:

1. Open Apple menu > System Settings > Privacy & Security.
2. Scroll down to Security and click Open Anyway for Flowmo.
3. Confirm by clicking Open and entering your Mac password if asked.

This creates an exception for Flowmo only. Do not disable your Mac's security
settings globally and do not use Terminal commands to bypass them. Apple's
instructions are at https://support.apple.com/102445.

USING FLOWMO

Type an intention and start. Focus counts upward until you stop; Flowmo is not
a 25-minute countdown timer and there is no Focus pause button. This is preview
software, so do not use it as the only copy of anything important.

The loop is: write an intention, prepare, Focus, take earned Break, leave a next
step in Reflection, then finish. Focus now skips the remaining preparation.
Focus scene opens the larger horizon canvas; Back to window restores the
smaller window while the clock continues. Park thought saves a distraction for
later. Reflection can turn a parked thought into the next step, and Done puts
that step back into editable Idle without starting another session.

Standard Mac menus provide Quit, clipboard editing, Undo/Redo, and window
controls. Build 8 renders the Distant Horizon live from your session: dawn
gathers as you prepare, warms as rest is earned, and settles as rest ends.
Focus still counts up without a finish line. Quiet controls and window chrome
use Liquid Glass on macOS 26 and later; primary actions remain solid ivory.
The Guard list now sits in a card, and Mini shows the full earned-break time.
The illustrated first-run tutorial remains available through Data > How it works.

Please retest Classic and Mini, Scene entry and Back to window, dragging and
resizing the Scene, Guard list scrolling, and Reduce Motion. Full VoiceOver,
real Focus Guard interception, and a fresh recipient's first opening still need
manual verification before this candidate is approved for sharing.

After quit or sleep recovery, the clock stays frozen until you choose Continue
or Restart. Simply opening a window does not resume it. Please check first-run
guidance, repeat access to the tutorial, readable text, and keyboard controls
alongside your ordinary session.

OPTIONAL TERMINAL COMMAND

The Mac app ZIP does not install the separate terminal command. If you receive
a matching terminal archive, verify its separately supplied checksum, extract
it, and run ./install.sh from that folder. It installs into ~/.local/bin and
prints the PATH instruction. Keep the bundled artwork beside the executable;
the installer places the complete payload under ~/.local/libexec/flowmo.
Start with flowmo --help and flowmo --version.
The command shares the Mac app's local session. To upgrade, quit running
Flowmo instances and use ./install.sh --replace. Removing ~/.local/bin/flowmo
uninstalls the command while preserving session data. Downloaded engineering
archives may be blocked by macOS; do not disable security or remove quarantine.

PRIVACY

Flowmo keeps its session data on this Mac. It has no Flowmo server, advertising,
third-party analytics, or third-party crash-reporting SDK, and it does not
upload your session text. This ad-hoc Mac preview cannot use the signed CloudKit
capability, so cross-device sync is disabled in this package. A full Flowmo data
export is private; do not attach it to a bug report.

REPORTING A PROBLEM

For ordinary bugs, use the project’s public bug-report form or reply privately
to the person who sent you the preview:
https://github.com/francarraras/flowmo-dev/issues/new?template=bug-report.yml

Include:

- Flowmo version 1.0 (build 8)
- your macOS version and Mac model
- what you did
- what you expected
- what happened instead
- the shortest steps that make it happen again

While Flowmo is idle, choose Data > Export Redacted Diagnostics and attach that
file if possible. It excludes intention, parked-thought and recall text,
selected app identifiers, and local store paths. Do not send screenshots or
exports containing private session text. For sensitive privacy or security
concerns, follow the repository’s SECURITY.md instructions and use a private
channel; do not include those details in a public issue.

UPDATES

This app does not update itself. Obtain an update from the same official
release page or private sender. Quit Flowmo, replace Flowmo.app in Applications,
and reopen it. Your local Flowmo data normally remains in place.

REMOVE FLOWMO

To remove both the app and its data, first open Flowmo while idle, choose Data >
Delete All Data, and confirm. Then quit Flowmo and move Flowmo.app from
Applications to Trash. Moving only the app to Trash does not remove its local
data.
