# GitHub

## See the flow in 25 seconds

Set an intention, settle in, and let Focus count up. End Focus when you choose; your effort earns your break. Leave an optional next step before returning to idle.

The illustrated example condenses time and uses the default 5:1 focus-to-break ratio. Mac and terminal preview downloads are available in Releases; the iPhone app is installed through Xcode.
