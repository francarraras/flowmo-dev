# Flowmo roadmap

The shipped loop stays in [`PROJECT.md`](PROJECT.md). This file lists later product work. It does not change current behavior.

## Current state

Shipped:

- Mac window, compact visual rules, pin, mute, and phase cues
- Focus Guard
- menu-bar clock
- `flowmo live`, CLI verbs, and `status --json`
- local iPhone app
- iPhone Home Screen widget

Mac and iPhone still use separate local files. Idle shows today's total only. There is no history browser, cloud sync, Watch app, Live Activity, or theme system.

## Order

### 1. One session across Mac and iPhone

Use an Apple-supported private sync mechanism only after its signing, conflict, offline, and recovery behavior is proven.

Required behavior:

- one canonical live session
- no silent merge of two Focus sessions
- timestamps remain the clock
- opening a remote session does not recovery-pause it
- local operation remains available when sync is unavailable

Do not add a Flowmo server or account dashboard to work around Apple platform limits.

### 2. History

A plain list of completed sessions is enough: intention, Focus duration, and date. Idle remains today's total plus Start.

No scores, streaks, charts, Home tab, flashcards, or spaced-repetition system.

### 3. Visual options

The current black and cyan frame remains the default. Any future visual options must not create a second product, add a dashboard, or put progress on Focus.

## Later

Watch, Live Activities, App Store work, monetization, and learning beyond the break-ratio rule stay behind the items above.

## Do not change

- Focus counts up until the user stops.
- No Pause control during Focus.
- Focus has no 0–100% ring.
- The Mac window remains the main Mac product.
- The CLI, menu bar, terminal, and widget remain supporting views.
- Do not resurrect screens or architecture from `~/Flowmo`.
