## Where v1 actually ended

Shipped: Mac window (loop, visual pass, pin, mute, cues), Focus Guard, menu-bar glance, `flowmo live`, CLI verbs + `status --json`, iPhone local face of the same Core.

Still true:

- Mac `~/.flowmo` and iPhone container are **two files**. No shared live session.
- Idle shows **today** only. History exists in JSON; there is no browser.
- Look is one black + cyan pass, not packs.
- Learning is **break ratio** only.

The old iPhone product was a different identity: Home, five tabs, protocol toggles, consolidation, reflection, SM-2, App Store launch. v2 is **not** that resurrection.

## Recommended order (one slice at a time)

Each slice still needs specify → design → tasks and a **sign** before code.

### 1. iPhone widget (glance, not a session)

**Why first.** iPhone v1 already said widgets come after the app exists. Lowest loop risk. Matches Mac glance: clock only, tap opens the app, does not Continue.

**Honest constraint.** WidgetKit cannot tick Core. It snapshots. Use an App Group so the widget reads the same `world.json` the phone writes. Timeline refresh on phase change + a coarse schedule. Focus still counts up from timestamps when the widget reloads; it will lag between reloads. That is acceptable for a glance.

**Out:** Live Activities, Watch, Start/Stop from the widget, a second engine.

**Spike or stop:** App Group + widget extension reads `Store(root:)` and shows `Format.glance`. If App Group or sandbox blocks the JSON lock, stop.

### 2. iCloud (one live session)

**Why second.** Widgets without sync still leave Mac and phone as two clocks. PROJECT already named iCloud after a working phone.

**Hard problem.** One live session + file lock does not map to “two devices online.” Need:

- One CloudKit (or iCloud Documents) container.
- Conflict rule: **one live**. If both have `live`, last writer must not silently merge two focuses. Prefer: device that already has `live` wins; the other becomes paused or refused to start.
- Kill/cold start pause stays local (process death), not “the other device opened the file.”

**Spike or stop:** two simulators / Mac + phone share `world.json` via iCloud Documents with a documented conflict rule. If merge creates two lives or a 25/5 feeling, stop.

**Out:** accounts, a Flowmo server, Watch until this works.

### 3. History (inspect, not a dashboard)

**Why third.** Agents already see `recentFocusSeconds` in `status --json`. Humans still cannot. A **list of completed sessions** (intention, focus length, date) is enough. Idle stays today-total + Start. No scores, streaks, or charts.

**Out:** Home tab as the product, flashcards, SM-2, “why the ratio moved” lecture (that can be a one-line field later).

### 4. Theme packs (only if you want a look decision)

This is a brand reopen, not an engineering need. Default stays the signed compact pass. Packs must not add Home or a light mode as a second product.

### Explicitly later than those four

Watch, Live Activities, App Store, monetization, CLI as a lifestyle, flashcards / consolidation / reflection from `~/Flowmo`.

Small **non-v2** chores (do not need this file): physical-device proof, Apple Developer signing, `flowmo set-config` for ratio if an agent needs it.
